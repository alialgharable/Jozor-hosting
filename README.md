# 🧥 Jozor – 3D Hoodie Customization Platform (In Progress)

Jozor is a web-based platform focused on interactive clothing customization.  
The main feature currently under development is a **3D hoodie customization system**, allowing users to design their own hoodie in real time.

> ⚠️ This project is still under testing and development. More features may be added in future updates.

---

## 🚀 Live Demo (Testing Version)
🔗 https://jozor-hosting.vercel.app/index.html

> This version is hosted for testing **quality and performance only**.

---

## ✨ Features

### 🎯 3D Hoodie Customization
- Interactive **3D hoodie model**
- Full rotation and smooth interaction
- Zoom in and out for detailed editing

### 🎨 Design Areas
Users can customize multiple parts of the hoodie:
- Chest
- Back
- Left sleeve
- Right sleeve

### 🖼️ Custom Content Tools
- Upload and place **images**
- Add **custom text**
- Resize, position, and adjust elements dynamically

---

## 🛠️ Technologies Used
- **JavaScript**
- **Three.js** (3D rendering)
- **HTML & CSS**
